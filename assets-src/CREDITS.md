# Asset credits

Every asset below is CC0 1.0 (public domain dedication). I checked the license on each source page on 2026-11-22, and kept only assets whose page says CC0. Attribution isn't required, but it's listed here anyway.

Folder layout: each asset has its own folder. `archive/` holds the original download and its extracted files. `glb/` holds the GLB I converted with Blender 5.2 headless, from FBX where possible. Animation names in GLBs converted from Quaternius FBX files were cleaned (for example `Armature|Armature|TRex_Idle` became `Idle`).

## In the game now (Dino Jungle uses only these creature models)

All realistic models are from Grab3D (https://grab3d.com), each page states "CC0 1.0 (public domain)". The "light" GLB was downloaded into `dinos/grab3d/<name>/model.glb` (with the source `page.html`), then slimmed for tablets with `scripts/slim_model.py` (about 14k triangles, 1024 px textures) into `dinos/grab3d/slim/`. They are unrigged sculptures; `godot/assets/dino_walk.gdshader` adds the walking motion.

No CC0 realistic Apatosaurus, Parasaurolophus or Protoceratops was found: Grab3D has none, Sketchfab's matches are CC-BY or non-commercial (and need a login to download), and Smithsonian Open Access has only fossil skeletons. Their source folders stay in `dinos/` for reference only.
